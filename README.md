# Coding 1: In-class assignment 4 — conditionals, loops, and functions

You have ten minutes. Read five lines of Python and answer two questions.

## Task

Open `assignment.py`. Write short Python comments beginning with `#` below each
`# Your answer:` prompt. Answer both parts of each numbered question in your own
words. Predict the output before running the code. **Do not change the code.**

Running it afterwards to check your answers is optional. No packages or data
files are needed. From this repository's folder, use your course Python setup:

```bash
uv run python assignment.py
```

## Submit

1. Fork this repository to your own GitHub account.
2. Clone **your fork** and open its folder in VS Code.
3. Add your answers to `assignment.py` and save it.
4. In the terminal inside that folder, run:

   ```bash
   git add assignment.py
   git commit -m "add comments"
   git push
   ```

5. Check that your answers are visible in your fork on GitHub before leaving
   class. You do not need to open a pull request.

## Marking

Each numbered question is worth one point for a correct answer and explanation.

- **2**: both questions answered correctly and explained.
- **1**: one question answered correctly and explained.
- **0**: neither question answered correctly, or no substantive answers.
